                    물욕 가득한 8월,, 갖고싶은것을 정리해보았다.

                    첫번째는 다이어리 커버! 레몬색이 넘 이쁘다 ㅎㅎ

                    #

                    두번째는 소파 앞에 둘 사이드테이블

                    이것저것 봤는데 요게 가운데 홈이 있어서 덜밋밋해보여서 제일 예쁜것같다. ㅎㅎ

                    #

                    세번째는 소파 옆에 둘 협탁!

                    이전에 본것들보다 예쁘고 가격도 합리적이어서 산다면 요걸 살것같다.

                    #

                    네번째는 블랙 선반!!

                    지금 검정 행거가 있는곳에 두면 분위기도 깔끔하고 예쁠것같다.

                    다만 행거를 어디 둘지가 애매해진다 ㅠㅠ

                    #

                    요건 사고싶은것 1순위인 트렌치코트..

                    봄부터 사고싶었는데 이번엔 진짜 살것이다.

                    다만 이번달 가용현금이 25만원 뿐이고 남은날은 16일이라 하루에 15000 쓰면 딱 떨어져버리고

                    엄마아빠 올라오면 그래두 밥한번 사야하니까 45000 넘을거 생각하면 이번달은 참아야한다!

                    #

                    그리고 지금 읽는 책 다읽으면 살 책

                    타인의 감정에 휘둘리지 않는 경험을 하니까, 정확히는 덜 휘둘리고 나만의 공간에서 다시한번 생각해볼수있는 경험을 하니까 이게 얼마나 좋은건지 내가 얼마나 힘들게 살았던건지 느껴져서 관련된 책을 조금더 읽고 싶었다.

                    마지막은 요즘 공부중인 딥러닝 책의 실물책 버전!
