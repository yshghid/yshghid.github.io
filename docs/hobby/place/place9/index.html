                                      테라로사 포스코센터점 #

                                      #2026-09-06

                                      올만의 혼카페 ㅎㅎ 예전부터 가보고싶었던 테라로사 포스코센터점을 왔다.

                                      내심 사진빨이려나 했었는데 탁 트이고 넘 예뻤던 내부 !! 1층 가장자리에 간단하게 앉을수있는 공간이 있고, 올라가는 길에 좌식 자리, 2층에는 테이블 자리가 있었다.

                                      커피는 머 시키지 하아가 르완다 나비라리는 원두를 처음보는것 같아서 시켜봤다. 원래는 케냐 마실랬는데 아이스 메뉴 되는게 한정이래서 요걸로 골랐당

                                      기다리면서이쁜 1층 자리랑 베이커리 구경

                                      배고팠으면 시켰을텐데 배가 안고파서 커피만 시켰다.

                                      요게 내가시킨 원두같은데 산미가 강해서 무난무난 마싰었다 ㅎㅎ

                                      오랜만에 나와서 책도 읽고 글도 쓰고 생각 정리도 하고 음악도 들으니까 너무 좋았다.

                                      특히 음악이 가사 없는 클래식이어서 책읽기에 좋은 장소였다 ㅎㅎ 공간 크기에 비해 시끄럽지도 않아서 한번쯤 더 갈수도 있을것같다.

                                      다음에 가면 밥 안먹고가서 빵도 시키고, 조금더 일찍 가서 창가 자리에 앉아보고싶다!
