                    들어가니까 완전 쌓여있던 소금빵들!!

                    원래는 빵을 먹어보고 싶었었는데 넘 배부른채로 간거라 티라미수랑 앙금빵? 시켰다.

                    빵은 무난무난했구 커피가 생각보다 맛있었다.

                    비가와서인지 더 운치있는것같은 내부

                    요런 오브제들 하나하나 넘 특이하구 이쁘다.

                    엄청 불편해보이지만 갬성있는 자리 ㅎㅎ

                    카페 자체는 이쁘고 커피도 맛있었는데, 주말이라 그런지 사람이 너무 많아서 시끄러웠다.

                    그리고 버스로 접근성도 좋은편은 아니라 평소에는 잘 안갈것같지만 약속 생기면 택시타고 가볼만한곳같다 ㅎㅎ
